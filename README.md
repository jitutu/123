# 校内智能网上阅卷系统

面向学校内部使用的小型私有化网上阅卷平台，解决传统人工阅卷中试卷搬运困难、批改效率低、成绩统计慢、阅卷过程无法追踪等问题，实现**答题卡数字化、客观题自动识别、教师在线阅卷、成绩自动统计、学生在线查看成绩与批注**。

## 核心功能

- **登录与权限**：超级管理员 / 管理员 / 教师 / 学生 四类角色，账号密码登录，接口级权限控制
- **用户管理**：管理员创建教师、学生账号（默认密码 `123456`），超级管理员管理管理员账号
- **考试管理**：创建考试（名称、日期、科目、参考学生）、上传答题卡模板
- **答题卡模板配置**：Canvas 鼠标框选正面/反面区域、准考证区域（条码 / OCR / 数字涂卡三种模式）、客观题选项（单选 / 多选 / 判断）、主观题答题区域，坐标一键保存
- **阅卷设置**：配置客观题标准答案与分值、主观题分值、双人评分（差值阈值内取平均，超阈值取后评作为终评）
- **答题卡识别**：批量上传答卷后自动执行 OMR 识别——识别准考证号并匹配学生、识别客观题涂卡并自动评分
- **在线阅卷**：左侧答题卡图片（缩放 / 拖动 / 正反面切换）+ Canvas 批注（画笔 / 文字 / 对勾 / 叉号 / 圈画 / 下划线 / 橡皮，自动同步保存），右侧逐题评分自动保存，主观题答题区域自动切割查看
- **成绩管理**：自动汇总客观题 + 主观题得分，支持结束阅卷、发布成绩、导出 Excel
- **学生端**：查看考试、成绩、逐题得分、答题卡图片与教师批注（支持缩放）

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 后端 | Python 3.11 + Flask |
| 数据库 | SQLite（Flask-SQLAlchemy） |
| 认证 | Flask-Login |
| 图像识别 | OpenCV（OMR 涂卡识别）、可选 PaddleOCR / pyzbar |
| 导出 | openpyxl（Excel） |
| 前端 | HTML / CSS / 原生 JavaScript（Jinja2 模板 + Canvas） |

> OpenCV 使用 `opencv-python-headless`（服务器/无 GUI 环境）；桌面环境可替换为 `opencv-python`。PaddleOCR 与 pyzbar 为可选依赖，缺失时自动降级（条码/OCR 识别不可用，数字涂卡识别不受影响）。

## 快速开始

### 1. 安装依赖

```bash
cd OnlineExamSystem

# 安装核心依赖
pip install -r requirements.txt
```

### 2. 启动系统

```bash
python3 app.py
```

启动后访问 `http://127.0.0.1:8000`。首次启动自动创建数据库（`database/exam.db`）并初始化默认账号与科目。

### 3. 默认账号

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 超级管理员 | admin | 123456 |
| 管理员 | manager | 123456 |
| 教师 | teacher1 | 123456 |
| 学生 | 001（张三） | 123456 |

## 使用流程

1. **管理员登录** → 用户管理创建教师与学生
2. **创建考试** → 选择科目与参考学生
3. **上传答题卡模板** → 进入区域框选配置，框选正面/反面/准考证/客观题/主观题区域
4. **阅卷设置** → 填写客观题答案与分值、主观题分值，按需开启双人评分
5. **上传答卷** → 批量上传答卷图片，点击"执行识别"自动匹配学生并识别客观题
6. **教师阅卷** → 教师登录进入在线阅卷，逐题评分、Canvas 批注
7. **成绩管理** → 结束阅卷自动汇总成绩，发布成绩，导出 Excel
8. **学生查看** → 学生登录查看成绩、答题卡与教师批注

## 项目结构

```
OnlineExamSystem
├── app.py                  # 应用入口与初始化
├── config.py               # 配置
├── database.py             # SQLAlchemy / LoginManager 实例
├── models.py               # 数据模型（users/students/exams/questions/papers/scores 等）
├── permission.py           # 角色权限装饰器
├── routes/                 # 路由
│   ├── auth.py             #   登录/登出
│   ├── admin.py            #   管理员：用户/考试/模板/设置/识别/成绩
│   ├── teacher.py          #   教师：在线阅卷/评分/批注
│   └── student.py          #   学生：成绩/答题卡详情
├── services/               # 业务服务
│   ├── exam_service.py     #   考试与模板服务
│   ├── recognize.py        #   识别服务（准考证匹配 + 客观题识别 + 自动评分）
│   └── score_service.py    #   成绩计算与 Excel 导出
├── recognition/            # 识别核心
│   ├── omr.py              #   OMR 涂卡识别
│   ├── ocr.py              #   OCR 数字识别（可选 PaddleOCR）
│   └── barcode.py          #   条码识别（可选 pyzbar）
├── templates/              # 页面模板（admin/teacher/student/login/base）
├── static/                 # CSS / JS（模板框选、阅卷批注）
├── uploads/                # 运行期文件（模板图/答卷/备份）
├── database/               # SQLite 数据库文件（运行期生成）
└── tests/                  # 测试（生成测试答题卡 + 端到端测试）
```
